# Build a cohesive experience featuring: 1

Build a cohesive experience featuring:
1. Marketing Landing Page:
- Overrank.ai inspired design (modern white + electric purple & blue glows).
- Floating real-time success toasts (+1 Backlink, +1.8k Traffic, Cited by Perplexity).
- Google & Perplexity live search winner card.
- CMS & AI Integration logos (WordPress, Shopify, Webflow, ChatGPT, Perplexity).
- Pricing table ($39, $79, $149).
- Prominent "View Live Demo" and "Get Started" buttons that navigate into the Dashboard.
2. Interactive User Dashboard (/dashboard):
- Overview Tab: Simulated Search Console traffic graph, articles published count, and citation rate.
- Articles & Calendar Tab: List of generated articles with status (Published / Scheduled / Draft), word count, and target keywords.
- CMS Integrations Tab: Simple setup cards for WordPress, Shopify, and Webflow (API key / URL input).
- Quick Action: A "Generate Article Now" modal that simulates AI topic discovery and article generation.
